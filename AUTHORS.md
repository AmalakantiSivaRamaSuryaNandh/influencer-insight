## Project origin

This repository reconstructs the final-year project concept **“Influencer
Insight: Unveiling Top Instagram Influencers Using NLP.”** The report-inspired
scope is the CSV dataset, NLTK text preprocessing, category matching, weighted
influencer scoring, and Flask interface.

The production structure, sample dataset, exact score weights, validation,
responsive design, tests, repository community files, continuous integration,
and deployment configuration are documented additions made for this repository.
