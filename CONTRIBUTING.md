# Contributing

Thank you for improving Influencer Insight.

1. Create a branch from `main`.
2. Keep the sample data fictional and free of personal information.
3. Add or update tests for every behavior change.
4. Run `python -m pytest` before opening a pull request.
5. Explain whether a change comes from the source report or is a new addition.

For scoring changes, update the code, tests, README, and methodology page together
so users can always understand how a result was produced.
