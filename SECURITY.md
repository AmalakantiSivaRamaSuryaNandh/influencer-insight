# Security policy

## Supported version

The latest commit on `main` is the supported educational version.

## Reporting a vulnerability

Please do not publish credentials, private data, or exploit details in a public
issue. Use GitHub's private vulnerability reporting feature for this repository
when it is available. Include the affected file or route, reproduction steps,
impact, and a suggested fix if known.

This project uses fictional sample data and does not require Instagram or other
third-party credentials. Never commit secrets or replace the sample CSV with
personal data.
