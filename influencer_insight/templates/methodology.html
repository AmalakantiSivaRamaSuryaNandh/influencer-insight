Transparent by design

How the recommendation is produced

This implementation follows the report's documented CSV, NLP, filtering, and ranking flow.

1

Load and validate

Pandas reads the CSV and verifies every required text and numeric field before analysis.

2

Preprocess text

NLTK lowercases and tokenizes the text, removes punctuation and stop words, and then lemmatizes each token.

3

Match a category

The requested category tokens are compared with each influencer's category and biography tokens.

4

Rank matches

Matching profiles are ordered by their calculated influence score, with followers breaking a tie.

Implementation assumption

Influence score

followers × 0.10 + likes × 0.40 + comments × 0.30 + shares × 0.20

The source report names these four weighted metrics but does not provide exact weights. These values are transparent, testable choices made for this reconstruction.

Addition beyond the report An engagement-rate percentage is also shown as supporting context; it does not change the ranking.
